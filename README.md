# Deepak Portfolio

## Project Info

This is my personal portfolio website built to showcase my skills, projects, and experience as a Full Stack/MERN Developer.

It is a responsive and modern portfolio site built using **React, TypeScript, Vite, Tailwind CSS, and shadcn/ui**.

## Live Demo

🔗 [Live Demo](https://deepak-portfolio-beta-peach.vercel.app/)
📂 [GitHub Repository](https://github.com/techbydeepak/deepak-portfolio)

## Features

* Responsive design for mobile and desktop
* About section with skills and technologies
* Projects showcase with GitHub links
* Contact form
* Clean and modern UI
* Reusable UI components with shadcn/ui
* Fast development and build performance with Vite
* Type-safe development with TypeScript

## Tech Stack

* **Frontend:** React + TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **UI Components:** shadcn/ui
* **Deployment:** Vercel

## Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

You can install Node.js using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Steps to Run Locally

```bash
# Step 1: Clone this repository
git clone https://github.com/techbydeepak/deepak-portfolio.git

# Step 2: Go to the project folder
cd deepak-portfolio

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The application will be available at the local development URL shown in your terminal.
